# Dynamic ATS - منظومة إدارة واستقطاب الكفاءات الذكية

منصة متكاملة وحديثة لإدارة عمليات التوظيف وتتبع المرشحين (Applicant Tracking System) مع توافق كامل كـ Web App للهواتف والحواسيب، ودعم نظام الصلاحيات المتقدم (RBAC)، ولوحات كانبان التفاعلية، والربط الذكي بين طلبات الاحتياج ومسار التعيين.

---

## 🌟 أبرز مميزات المنصة

- 📱 **Web App متجاوب بالكامل**: دعم PWA كامل مع قائمة جانبية ذكية (Slide-over Drawer) وشريط ملاحة سفلي مخصص للهواتف لسهولة الاستخدام بإبهام اليد.
- 📋 **طلبات الاحتياج والاعتمادات (Requisitions & Approvals)**:
  - دورة اعتماد متعددة المستويات (HR ← المالية ← الإدارة العليا).
  - تتبع دقيق للمقاعد المستهدفة (Headcount Target vs. Filled).
  - ربط تلقائي فوري: اكتمال طلب الوظيفة عند تعيين العدد المطلوب في مسار كانبان، وإعادة فتحه تلقائياً في حال تغيير حالة المرشح.
  - إحصائيات متقدمة تشمل إجمالي الطلبات المرفوضة والنشطة والمكتملة.
- 📊 **مسار المرشحين ولوحة كانبان (Pipeline Kanban)**:
  - سحب وإفلات تفاعلي (Drag & Drop) مع تحجيم ديناميكي لقوائم المراحل.
  - بطاقات المرشحين الذكية مع درجات مطابقة الذكاء الاصطناعي (AI Matching Score).
- 🌐 **بوابة التوظيف وروابط الـ UTM (Careers Portal & Sourcing)**:
  - روابط تقديم عامة مستقلة (`PublicJobApplicationPage`) جاهزة للمشاركة والنشر.
  - تتبع مصادر الاستقطاب (LinkedIn, Indeed, Referrals, etc.).
- 🤝 **بنك المواهب وإدارة العلاقات (Talent Pool CRM)**:
  - تصفية وبحث متقدم بالمهارات والخبرات.
  - نافذة منبثقة متكاملة لتفاصيل المرشح مع إمكانية التواصل المباشر.
- 🔒 **مصفوفة الصلاحيات (RBAC & Security)**:
  - دروع حماية الرواتب (Salary Shields) وعزل البيانات الحساسة حسب دور المستخدم.
- ⚡ **محرك الأتمتة والرسائل (Automations Engine)**:
  - إرسال إشعارات وخطابات قبول/رفض تلقائية للمرشحين.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 18 + TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS + Custom Design System
- **Icons**: Lucide React
- **Themes**: دعم كامل للوضعين الداكن (Dark) والفاتح (Light) مع دعم اللغتين (عربي / English)

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الحزم

# 2. تشغيل خادم التطوير
npm run dev

# 3. بناء نسخة الإنتاج
npm run build
```
